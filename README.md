# 材料数据计算工具

这是供工厂人员在本机估算材料可冲圆片数量的离线工具。输入材质、厚度、宽度、重量和冲料方式后，工具按已确认的剪口、单重及数量规则计算，并展示中间值，便于核对。v0.1.2 同时提供 Windows 安装版、便携版和原有离线网页。

## 主要功能

- **单次计算**：支持 410、201、304、316 材质及单排、双排冲料；可选第 1 套圆片密度算法或第 2 套圆片密度高级算法。单排另可选第 3 套方片密度算法。默认材质为 201、冲料方式为双排、公式为第 1 套。
- **批量计算**：粘贴表格数据或导入 CSV、XLSX；提供两种格式的模板，逐行显示结果或错误。每次最多 500 条，导入文件不超过 2 MB。
- **结果处理**：单次结果及批量成功行可导出为 CSV、XLSX，或通过浏览器打印、另存为 PDF。
- **历史记录**：在当前应用的数据目录保存最多 500 条成功结果，可筛选、查看、按当前参数重新计算、确认后删除单条记录，并可将历史备份为 JSON 或合并恢复。重算不会改写旧结果。
- **参数维护**：可修改四种材质各两套密度系数、单排及双排冲料圆片比例系数、双排剪口换算值，共 11 项；保存或恢复默认值前会要求确认，修改仅影响后续计算。支持参数 JSON 备份和导入。

## Windows 桌面版

从 [GitHub Releases](https://github.com/Yujay-Si/ss-mat-data-calc/releases/latest) 下载：

1. **安装版**：双击 `SSMaterialDataCalc-0.1.2-Setup.exe` 安装，再从开始菜单或桌面快捷方式打开。
2. **便携版**：解压 `SSMaterialDataCalc-0.1.2-win32-x64.zip` 的全部内容，双击其中的 `SSMaterialDataCalc.exe`。不要只复制 EXE，配套文件也是运行所需。

两版均无需账号和服务器，可离线运行。桌面版数据保存在 Windows 用户配置目录的 `SSMaterialDataCalc` 应用数据中；安装版和便携版在同一 Windows 账户下使用同一份数据。网页和桌面版不会自动同步。请先在原网页的“历史记录”和“参数维护”分别导出 JSON，再到桌面版分别导入。导入参数只影响之后的新计算，旧历史结果保留原快照。

安装版启动后约 12 秒及运行期间每小时检查一次 GitHub 正式 Release；有新版时自动下载，下载完成后询问是否立即重启安装。选择“稍后”可继续工作，更新会在下次启动时生效。便携版按相同频率检查；发现新版便携包后仅提示打开下载页，需自行下载并解压。计算功能始终可离线使用，断网时仅无法检查更新。v0.1.1 尚无更新检查代码，使用旧版的用户必须手动安装 v0.1.2 一次，之后安装版才能自动更新。

桌面程序尚未进行代码签名，Windows 可能显示“未知发布者”提示。升级前建议分别导出历史记录和参数 JSON 备份。

## 离线网页

无需安装依赖、启动服务器或注册账号。在 Windows 上：

1. 将项目完整保存到本机，保持 `outputs/preview-site/` 内文件和 `vendor/` 目录的相对位置；不要只复制 `index.html`。
2. 用现代浏览器直接打开 [`outputs/preview-site/index.html`](outputs/preview-site/index.html)（例如双击文件）。页面可通过 `file://` 离线使用。
3. 在“单次计算”输入数值，或切换到“批量计算”下载模板并导入文件。

历史与自定义参数保存在当前浏览器的本地存储中。更换浏览器、移动网页位置或清理浏览器数据可能导致原数据无法读取；请分别导出历史与参数 JSON 备份。恢复时，只导入可信的本工具备份。

## 从源码构建桌面版

在 Windows x64 上安装 Node.js 和 npm，然后运行 `npm ci`、`npm test`、`npm run test:desktop`、`npm run make`、`npm run test:release-assets`。桌面自检会检查计算、XLSX、参数备份下载、PDF 打印和重启后的数据留存。构建脚本会在项目路径含中文时暂存源码到系统临时目录再运行 Squirrel，安装包和便携压缩包最终输出至 `out/make/`。每个正式 GitHub Release 除安装包和便携 ZIP 外，还须附上构建生成的 `RELEASES` 与对应 `*-full.nupkg`，且版本号、文件大小和哈希必须匹配；缺少这些文件会导致安装版更新失败。开发依赖和构建产物不提交到仓库。

## 输入输出示例

以下是演示数据。在“单次计算”选择 **201 / 双排 / 第 2 套圆片密度高级算法公式**，输入：

| 输入项 | 值 |
| --- | ---: |
| 厚度 | 0.3 mm |
| 宽度 | 600 mm |
| 材料重量 | 100 kg |

默认参数下，输出的关键结果为：

| 输出项 | 值 |
| --- | ---: |
| 剪口 | 320 mm |
| 所选单重原值 | 0.191232 kg/个 |
| 页面显示单重 | 0.1912 kg/个 |
| 双排冲料圆片比例系数 | 0.824 |
| 预计圆片数量 | **430 个** |

数量按未舍入的单重计算，再向下取整：`floor(100 × 0.824 ÷ 0.191232) = 430`。自定义参数改变后，结果也会改变。

批量导入使用模板表头：

```csv
材质,厚度(mm),宽度(mm),材料重量(kg),冲料方式,单重公式
201,0.3,600,100,双排,2
```

此行在默认参数下得到剪口 **320 mm**、预计圆片数量 **430 个**。公式编号 `1` 为圆片密度算法，`2` 为圆片密度高级算法；`3` 仅用于单排的方片密度算法。旧版批量文件的公式 `1`、`2` 编号与当前版本相反，导入前需互换。

输入的厚度、宽度、重量均须大于 0。批量导出与打印只包含计算成功的行。使用前请保留完整网页目录；历史和自定义参数需由使用者自行备份。
