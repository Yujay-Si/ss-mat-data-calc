# 材料数据计算工具

这是供工厂人员在本机估算材料可冲圆片数量的离线网页。输入材质、厚度、宽度、重量和冲料方式后，工具按已确认的剪口、单重及数量规则计算，并展示中间值，便于核对。当前交付物是网页，尚无 Windows 安装包或 EXE。

## 主要功能

- **单次计算**：支持 410、201、304、316 材质及单排、双排冲料；可选第 1 套圆片密度算法或第 2 套圆片密度高级算法。单排另可选第 3 套方片密度算法。默认材质为 201、冲料方式为双排、公式为第 1 套。
- **批量计算**：粘贴表格数据或导入 CSV、XLSX；提供两种格式的模板，逐行显示结果或错误。每次最多 500 条，导入文件不超过 2 MB。
- **结果处理**：单次结果及批量成功行可导出为 CSV、XLSX，或通过浏览器打印、另存为 PDF。
- **历史记录**：在当前设备的当前浏览器保存最多 500 条成功结果，可筛选、查看、按当前参数重新计算、确认后删除单条记录，并可将历史备份为 JSON 或合并恢复。重算不会改写旧结果。
- **参数维护**：可修改四种材质各两套密度系数、单排及双排冲料圆片比例系数、双排剪口换算值，共 11 项；保存或恢复默认值前会要求确认，修改仅影响后续计算。

## 安装与打开

无需安装依赖、启动服务器或注册账号。在 Windows 上：

1. 将项目完整保存到本机，保持 `outputs/preview-site/` 内文件和 `vendor/` 目录的相对位置；不要只复制 `index.html`。
2. 用现代浏览器直接打开 [`outputs/preview-site/index.html`](outputs/preview-site/index.html)（例如双击文件）。页面可通过 `file://` 离线使用。
3. 在“单次计算”输入数值，或切换到“批量计算”下载模板并导入文件。

历史与自定义参数保存在当前浏览器的本地存储中。更换浏览器、移动网页位置或清理浏览器数据可能导致原数据无法读取；历史可导出 JSON 备份，当前版本尚不支持自定义参数独立备份。恢复历史时，请只导入可信的本工具备份。

## 输入输出示例

以下是演示数据。在“单次计算”选择 **201 / 双排 / 第 2 套圆片密度高级算法公式**，输入：

| 输入项 | 值 |
| --- | ---: |
| 厚度 | 0.3 mm |
| 宽度 | 600 mm |
| 材料重量 | 100 kg |

默认参数下，输出的关键结果为：

| 输出项 | 值 |
| --- | ---: |
| 剪口 | 320 mm |
| 所选单重原值 | 0.191232 kg/个 |
| 页面显示单重 | 0.1912 kg/个 |
| 双排冲料圆片比例系数 | 0.824 |
| 预计圆片数量 | **430 个** |

数量按未舍入的单重计算，再向下取整：`floor(100 × 0.824 ÷ 0.191232) = 430`。自定义参数改变后，结果也会改变。

批量导入使用模板表头：

```csv
材质,厚度(mm),宽度(mm),材料重量(kg),冲料方式,单重公式
201,0.3,600,100,双排,2
```

此行在默认参数下得到剪口 **320 mm**、预计圆片数量 **430 个**。公式编号 `1` 为圆片密度算法，`2` 为圆片密度高级算法；`3` 仅用于单排的方片密度算法。旧版批量文件的公式 `1`、`2` 编号与当前版本相反，导入前需互换。

输入的厚度、宽度、重量均须大于 0。批量导出与打印只包含计算成功的行。使用前请保留完整网页目录；历史和自定义参数需由使用者自行备份。
